# 3D model credits

Every model here is an original made for this portfolio.

`ojek.glb` (matic scooter) and `rider.glb` (its jointed rider) come from
`ojek-meja.blend`, kept outside this repository. They were exported from
Blender and optimized with `@gltf-transform/cli optimize --compress meshopt
--flatten false --palette false --simplify false`. Flattening is off so the
`RodaDepan_Poros` and `RodaBelakang_Poros` wheel pivots and the rider's
`Rig_*` joint pivots survive for animation.

`kampung/bangunan.glb`, `kendaraan.glb`, `alam.glb`, `props.glb` and
`aksesori.glb` are the kampung kit. They are generated by the Blender scripts
in `D:\projects-3d\kampung\scripts` (`build_kit.py`, kept outside this
repository) and optimized with `--compress false --prune-attributes false
--flatten false --instance false --palette false --simplify false`:
instancing is off so every part stays under its asset's named root, which the
game clones, and attributes are kept so roofs keep the texture coordinates
their normal maps need.
